## 🚀 Quick Start

**3 minutes to live deployment:**

1. **Get Groq API Key** (free): https://console.groq.com
2. **Deploy to Fly.io**:
   ```bash
   flyctl launch --name your-app
   flyctl secrets set GROQ_API_KEY=your_key
   flyctl deploy
   ```
3. **Done!** Visit `https://your-app.fly.dev`
